# Assignment 12 — AI Music Generation via a Free Cloud Model

This project uses the **public Hugging Face ACE-Step Model 1.0 Space** via its Gradio API (not a locally installed music model). The **ACE-Step 1.5 Space** can be used in a browser as an alternative. Both are hosted services; free ZeroGPU access has queues and daily quotas.

## Steps on Windows (VS Code / PowerShell)

1. Get a free account at https://huggingface.co/ and sign in.
2. Review the hosted demo: https://huggingface.co/spaces/ACE-Step/ACE-Step
3. Open this folder in VS Code.
4. In a PowerShell terminal, install:
   `python -m pip install --upgrade gradio_client requests`
5. Recommended: create a **new** read-only token at https://huggingface.co/settings/tokens and set it *in this same PowerShell session*:
   `$env:HF_TOKEN = "your-new-read-token"`
   Never share or commit tokens. The public demo may also work unauthenticated but has a smaller quota.
6. Run: `python generate_music.py`
7. A successfully completed call saves `generated_song.wav` (or whatever audio extension the service returns).
8. Listen to the song and verify the vocal lyrics and length. The requested 180 seconds are not guaranteed by the AI model.

## If a request fails

- The Space can be busy, rate-limited, changed, or unavailable; try it directly in a browser.
- See the Space's **Use via API** section for its currently supported parameters; Gradio APIs can change.
- If the 180-second request exceeds ZeroGPU limits, try a shorter length or try again when the free quota resets. Do not claim a 3-minute song was generated unless it exists and you have checked it.
- Browser alternative: https://huggingface.co/spaces/ACE-Step/Ace-Step-v1.5 (Custom mode, caption and lyrics, 180s, instrumental off).

## Submit

- `generate_music.py` — full Python source
- `prompt.txt` — style prompt
- `lyrics.txt` — original lyrics
- `generated_song.wav` (or returned extension) — **must be generated by you** after successfully running the code

No sample audio file is supplied in this ZIP. This is a reproducible project, not a claim that a remote generation was successfully completed.
